Мне интересно в этом проекте было реализовать несколько вещей:

• Живёт в трее и показывает текущий статус

• В настройках можно поменять длительность работы/отдыха/отсрочки, включить/выключить звуки, выбрать свой звуковой файл, настроить частоту обновления иконки и автозакрытие уведомлений

(Там зеленая кнопка Code -> Download ZIP)

Ниже подробная инструкция, как запустить его за 10 минут.

1. Подготовка
Тебе понадобится компьютер (Mac, Windows или Linux) и установленная программа Node.js (это движок, на котором работает бот).
• Скачай архив с ботом по ссылке выше и распакуй в папку.
• Зайди на nodejs.org, скачай версию LTS и установи её (просто нажимай "Далее").

2. Google API
Сыч работает на нейросети Gemini Flash. Она быстрая и бесплатная.
• Включи VPN (если ты в РФ, желательно выбери страну США, чтобы сработало наверняка, но работают некоторые страны Европы, но не все)
• Зайди на aistudio.google.com/api-keys.
• Нажми Get API key -> Create API key.
• Скопируй ключ, начинающийся на AIza....

3. Telegram
Создаем самого бота в Телеграме.
• Найди бота @BotFather.
• Напиши ему команду /newbot.
• Придумай имя и юзернейм (обязательно должен заканчиваться на bot).
• Он выдаст тебе Token. Скопируй его.

4. Твой ID
Чтобы бот слушался только тебя, нужно узнать свой цифровой ID.
• Найди бота @getmyid_bot.
• Запусти его.
• Скопируй цифры из строчки Your User ID (например: 2983152).

5. Сборка
Теперь соединяем всё вместе.
• В папке с ботом найди файл .env.example.
• Переименуй его в .env (убери точку и слово example).
• Открой этот файл любым текстовым редактором (Блокнот, TextEdit).
• Вставь свои данные после знака равно:
TELEGRAM_BOT_TOKEN=(сюда токен из п.3)
ADMIN_USER_ID=(сюда твой ID из п.4)
GOOGLE_GEMINI_API_KEY=(сюда ключ Google из п.2)
• Сохрани файл.
• Лайфхак для стабильности: У бесплатных ключей есть лимиты запросов. Чтобы бот не замолкал при активном общении, создай в Google еще несколько ключей и добавь их с новой строки, приписывая цифру:
GOOGLE_GEMINI_API_KEY_2=(второй ключ)
GOOGLE_GEMINI_API_KEY_3=(третий ключ)
и так далее. Бот сам будет переключаться между ними.

6. Запуск
• Открой эту папку в терминале (На Windows: правой кнопкой мыши внутри папки -> "Открыть в терминале").
• Напиши команду для установки библиотек и нажми Enter:
npm install
• Напиши команду запуска и нажми Enter:
npm start

Если собираетесь добавить его в группу, не забывайте дать ему права администратора, иначе он не будет видеть ваши сообщения типа "Сыч привет", т.к. в целях безопасности боты в Telegram без прав не видят сообщений пользователей

Как сделать, чтобы работал 24/7?
Если запустить на компьютере, бот уснет вместе с ним. Чтобы он работал всегда, нужен недорогой VPS-сервер (стоит ~400 ₽/мес).
Там процесс почти такой же, но нужно настроить автозапуск через PM2.

Сегодня с утра немного обновил Сыча

Гугл закрутил гайки с лимитами на API (всего ~20 запросов в день на топовых моделях), поэтому, чтобы Сыч не умирал к обеду, пришлось его немного переписать.

Что изменилось:

Раздвоение личности (Dual-Core AI)
Раньше Сыч тратил дорогие лимиты на всё подряд. Теперь обязанности разделены:
• Gemma 3 (27b-it): молча анализирует чат, решает, нужно ли отвечать, ставит реакции и обновляет досье на пользователей. У неё огромные лимиты, поэтому она берет на себя 90% рутины.
• Gemini 2.5 Flash: подключается только когда нужно сгенерировать смешной ответ, послушать голосовое или описать картинку.

Gemini 2.5 Flash lite (Fallback)
Если основные ключи всё-таки заканчиваются, бот больше не падает с ошибкой. Он автоматически переключается на запасную модель Flash-Lite. Он чуть проще, но зато Сыч остается в строю до конца дня.

Новая команда: «Сыч стата»
Показывает здоровье всех API-ключей и подробную статистику расхода: сколько запросов ушло на основу, сколько на лайт-версию, а сколько на Гемму. И какая сейчас модель работает.

По мелочи:
• В логах в консоли теперь нормальное время.
• Пофиксил баг, ошибки при окончании лимитов.

ClipGen 2.0.2: Прокси и Автономность

Выкатил важный апдейт. Главная цель — сделать программу полностью автономной и удобной для использования в РФ без лишних действий.

Что нового:

1. Нативная поддержка Прокси
Больше не обязательно держать включенным системный VPN. В настройках теперь можно указать свой прокси (поддерживаются HTTP и SOCKS5), и ClipGen будет обращаться к Google точечно через него. Обратите внимание на формат ввода: login:password@ip:port.

Где брать прокси:
Для тестов брал на proxy6.net (ссылка реферальная). Нужен «IPv4 Прокси» США/Европа (Но уточните, работает ли AI Studio в этой стране, в США точно работает, его и купил себе для теста).
Стоит 33 рубля в месяц. Можно оплатить картой РФ или криптой. Но конечно вы можете использовать любой свой прокси, если уже есть

2. Система обновлений
Теперь не нужно мониторить GitHub вручную. Программа сама в фоновом режиме проверяет наличие новых версий каждый раз при старте.
Если вышел апдейт — иконка в трее загорится синим цветом.
• Добавил ручную проверку по кнопке "Проверить обновления".
• Добавлена возможность «Пропустить версию», если обновляться прямо сейчас не хочется. ClipGen уведомит в следующий раз только, когда версия на GitHub опять изменится

3. Миграция настроек
Внедрил безопасную систему обновления конфига. При замене exe файла старый settings.json не перезаписывается, а аккуратно дополняется новыми параметрами. Ваши API-ключи и промпты остаются на месте.

4. Интерфейс
Вынес редактирование промптов в отдельное окно. Стало просторнее и удобнее работать с большими текстами промптов. Настройки моделей и API-ключей с прокси теперь не мешают

Сыч v1.1: Большой переезд на OpenRouter

Люблю праздники за то, что можно наконец-то сесть и спокойно покодить. Немного прокачал бота: прошлая версия быстро упиралась в бесплатные лимиты Google, поэтому я решил перевести Сыча на рельсы — OpenRouter.

В .env добавилась переменная OPENROUTER_API_KEY. Логика теперь такая: если ключ есть — бот работает через агрегатор, если нет — по старинке крутит бесплатные ключи Google (с их ротацией).

Что изменилось под капотом:

Экономика вопроса
OpenRouter дает доступ к 500+ моделям, но это удовольствие уже платное. Я разделил обязанности между нейронками, чтобы это стоило копейки, но работало круто.
Средняя цена за ответ получается такой:
• Анализ (Gemma 3 27B): ~0,006₽ (почти бесплатно, работает в фоне, решает, отвечать ли боту).
• Ответы (Gemini 3 Flash): ~0,10₽ (генерирует основные ответы).
• Поиск (Perplexity Sonar): ~0,43₽ (подключается только для поиска).

Архитектура RAG (Perplexity + Gemini)
Тут вылез нюанс: У gemini через OpenRouter нет доступа к интернету (в отличие от нативного Google API).
Поэтому я реализовал схему RAG:
Если вы спрашиваете про курс доллара, погоду или новости — запрос сначала летит в Perplexity Sonar. Это поисковая нейронка. Она пылесосит интернет и отдает актуальные факты со ссылками.
Эти факты скармливаются Gemini, и уже она выдает финальный ответ в стиле бота.
Итог: Актуальные данные, пруфы и фирменный стиль совы.

Учет часовых поясов

😎 ClipGen 2.3.0: Режим обучения и модульная архитектура

Большое обновление, которое делает ClipGen не просто инструментом автоматизации, а персональным репетитором.

Режим обучения (Learning Mode)

Промпт обучения можно настроить под себя. По умолчанию он объясняет грамматику, но вы можете переписать его как угодно — попросить разбирать стилистику, объяснять выбор слов при переводе, или фокусироваться на конкретных правилах.

Работает и для изучения языков. Переводите текст — получаете объяснение, почему слова переводятся именно так. Проверяете текст на иностранном — видите правила грамматики.

Объяснения появляются во всплывающем окне (исчезает через 3 секунды, если не навести курсор) и дублируются в логах.

Индивидуальная модель для каждого хоткея
Раньше все действия использовали одну глобальную модель. Теперь можно настроить:
• Ctrl+F1 — быстрая коррекция через Gemini Flash (дёшево и быстро)
• Ctrl+F2 — качественный перевод через GPT-5 (точнее)
• Ctrl+F3 — анализ кода через Claude Opus (умнее)
В карточке каждого хоткея появился переключатель «Своя модель». Включаете — выбираете провайдера и модель. Выключаете — используется глобальная настройка.

Полный рефакторинг архитектуры:
Под капотом — это новое приложение. 2 файла на 5000+ строк превратились в 26 модулей с чёткой структурой:
• core/ — конфигурация
• api/ — провайдеры Gemini и OpenAI
• ui/ — интерфейс по вкладкам
• utils/ — прокси, автозапуск, обновления
Это не только про «красивый код». Благодаря рефакторингу исправлены скрытые баги и упрощено добавление новых функций.

Раньше UI-класс наследовался от логики — это антипаттерн, который усложнял тестирование и создавал неявные зависимости. Теперь ClipGenApp собирает компоненты как конструктор. Каждый модуль можно тестировать отдельно.

Gemini и OpenAI теперь работают через единый интерфейс APIProvider. Добавить новый провайдер (Anthropic, Mistral) — это написать один класс на 50 строк, а не копировать код по всему проекту.

Про iOS. Если честно, подобного решения вроде бы нет. VPN в айфоне работает сразу на всё устройство, сделать отдельную песочницу без VPN не получится. На чистом Android есть штука под названием Частное пространство (Private Space). Задумывалась она вообще для обратной задачи, чтобы спрятать чувствительные приложения и данные. Но для нашего случая подходит идеально.

В чём суть. Частное пространство это фактически отдельный пользовательский профиль внутри вашего телефона, со своей авторизацией в Google. Приложения внутри живут в полной изоляции, как на только что купленном телефоне. У них нет доступа к вашим контактам, галерее, файлам. Но самое важное VPN включённый в основном профиле, не распространяется на частное пространство. Приложения оттуда ходят в интернет напрямую, без VPN. Ровно то, что нам нужно.

Как настроить:

• Настройки ➜ Безопасность и конфиденциальность ➜ Частное пространство
• Заведите отдельный новый Google-аккаунт специально под него
• Установите в него все РФ-приложения (банки, 2ГИС, Госуслуги и прочее), а из основного профиля их удалите
• VPN держите включенным в основном профиле, внутри приватного пространства VPN-клиент не ставьте

• Во все приложения придётся заново залогиниться
• Когда частное пространство заблокировано, приложения внутри полностью останавливаются. С одной стороны это плюс, никакой фоновой активности и батарею не жрут. С другой, пуши от банков тоже не приходят. Блокировку можно повесить не сразу, а, например, через 30 минут или при перезагрузке телефона
• Доступ к приложениям чуть менее удобный. Иконки нельзя вынести на рабочий стол, они открываются только из отдельной папки внизу списка приложений

До этого я сидел на NightTab, там были красивые ярлыки для быстрого доступа к сайтам. И решил всё объединить, взяв Tab Out за основу.

Что добавил:

• Быстрые ярлыки, как в NightTab, добавил drag-and-drop, с редактированием цветов и иконок прямо на странице. Можно загрузить свою SVG-иконку, выбрать цвет фона, перетаскивать между группами. 48 ярлыков у меня сейчас, по группам: поиск, облако, AI-инструменты, рабочие сервисы, dev.

• Погода: текущая температура, прогноз на сегодня и завтра, восход/закат, качество воздуха (AQI) с дельтой относительно вчера. Город выбирается в настройках.

• Курсы валют: доллар и евро по ЦБ РФ, крипта (BTC, ETH, SOL, TON) через CoinGecko. Со стрелками и разницей со вчера.

• Системные метрики: загрузка CPU и GPU, температуры, RAM, место на диске, VRAM, обороты кулера. Для температур нужен Libre Hardware Monitor, бесплатная утилита, которая отдаёт данные по HTTP. Всё остальное берётся из API Chrome.

• Пинг до важных серверов: Google, GitHub, рабочие хосты. Цветная точка + миллисекунды. Сразу видно, работает ли интернет и что именно лежит.

• Speedtest: замер скорости по кнопке через Cloudflare. Результат сохраняется и висит до следующего замера. В связи с последними событиями и тестами VPN для меня это актуально.

• Закреплённые вкладки (Pinned): вкладки которые всегда открыты (почта, мессенджеры, рабочие дашборды). Они исчезают из списка открытых и живут в своей секции. Что бы не мешали.

• Тёмная тема: светлая, тёмная, или автоматическая по закату/рассвету.

• Полный экспорт/импорт настроек в JSON. Переустановил винду, загрузил файл, всё вернулось.

Как это работает: всё живёт внутри расширения. Данные в chrome.storage.local. Погода и курсы тянутся напрямую из публичных API с кешированием. Когда вкладка в фоне, все запросы ставятся на паузу, нагрузка нулевая.

Как установить:
1. Скачать репозиторий (git clone или ZIP)
2. Открыть edge://extensions (или chrome://extensions)
3. Включить "Режим разработчика"
4. "Загрузить распакованное" > выбрать папку extension/
5. Открыть новую вкладку

Работает в Chrome и Edge на любой ОС: Windows, Mac, Linux. Единственное: системные метрики (температуры CPU/GPU) требуют Libre Hardware Monitor, который есть только под Windows. На Mac и Linux будут работать RAM, диск, погода, курсы, всё кроме температур.

Несколько важных вещей, которые стоит поднять перед тем как смотреть код:

Сервис изначально проектировался под AI, а не под ручной ввод. Пользователь в UI может немногое: загрузить документ, отметить план выполненным, оставить комментарий, поправить мелочь. Всё остальное делает нейронка.

Почему так. В таблице анализов 10+ полей: параметр, значение, единица измерения, референсный диапазон, статус, связь с визитом. Без этого FTS5-поиск разваливается, графики динамики пустые, кросс-ссылки между сущностями не работают.

Без AI сервис работает, но как обычная картотека, без того что делает его реально полезным.

К какой модели подключать.

В коде нет привязки к Anthropic. Это просто протокол: AI получает доступ к БД через HTTP+SQL и следует инструкциям из AI_COORDINATOR_GUIDE.md. Подойдут Claude Code, Cursor, Aider, Gemini CLI, Codex, локальные модели через Ollama. Гайды по каждому в docs/setup/.

Но: чем слабее модель, тем больше ошибок. На 70B-локалке рутинный перенос данных работает, клиническое мышление — нет. Речь о здоровье, так что советую не экономить на модели.

И главное: AI ошибается.

У меня был реальный случай: нейронка криво прочитала PDF «СОЭ 11++» как «Т4 свободный 11», получил ложный критический диагноз подозрения на гипертиреоз. Пришлось откатывать.

😎 ClipGen 2.4: Голосовой ввод

Большое обновление. ClipGen научился превращать речь в текст в любом приложении, полностью локально, без облаков и подписок.

Как это работает

Зажимаете горячую клавишу → говорите → отпускаете. Текст появляется там, где стоит курсор: в мессенджере, браузере, редакторе кода, в почте. Ничего не нужно копировать и переключать окна.

Голос вообще не уходит с компьютера. Модель работает прямо на вашей машине: без API-ключей, без интернета, без лимитов.

Скорость: реальные цифры

Я пользуюсь им уже третью неделю и в итоге остановился на движке Parakeet от NVIDIA. Вот замеры с моего ноутбука (RTX 3060):

• Фраза на 7–8 секунд речи: Parakeet распознаёт за 0.1 секунды на видеокарте, на процессоре — около секунды. Whisper large-v3 на видеокарте — 1.3 секунды
• Диктовка на 24 секунды: Parakeet — 0.3 секунды, Whisper — 2.9
• Получается, Parakeet работает примерно в 90 раз быстрее реального времени. Отпустил клавишу — текст уже стоит, буквально
• Видеокарта не обязательна: даже на процессоре выходит около секунды на обычной фразе
• Модель грузится в память за несколько секунд и дальше просто дежурит. Полежала без дела → сама выгрузилась и освободила память

Внутри два движка

• Whisper (OpenAI) — 99 языков, максимальное качество. Модели от tiny (75 МБ) до large-v3 (3 ГБ)
• Parakeet (NVIDIA) — 25 языков, включая русский. Очень быстрый, весит 2.5 ГБ

Как включить

Скачайте новый ClipGen.exe (ссылка внизу). Если уже пользуетесь — программа сама предложит обновиться
Нужен Python 3.10+ (бесплатно с python.org, при установке поставьте галочку «Add python.exe to PATH»)
Настройки → «Голосовая транскрибация» → включить
Выбираете движок и модель, жмёте «Установить / Скачать» → программа сама ставит компоненты и качает модель, с прогрессом и кнопкой отмены
Жмёте «Загрузить модель» или включите «Загружать модель при старте», чтобы всё было готово сразу после запуска

Как настроить горячую клавишу

Вкладка Промпты → «Добавить новое действие»
Тип действия → «Голосовая транскрибация»
Назначьте комбинацию, которую удобно держать зажатой
По желанию укажите язык (или оставьте автоопределение) и словарь-подсказку: впишите туда свои термины, имена и аббревиатуры — модель будет писать их правильно
Клавиш можно сделать несколько: одна под русский, другая под английский, третья со своей рабочей терминологией.

Из приятного

• В углу экрана маленький оверлей: запись → распознавание → готово
• Иконка в трее подсказывает цветом: красная → идёт запись, жёлтая → распознавание
• Звуковые сигналы в начале и конце записи (можно выключить)
• Фильтр галлюцинаций убирает фразы-паразиты, которые нейросети любят придумывать на тишине
• Лимит записи настраивается, по умолчанию 2 минуты

И под капотом много работы над надёжностью: служебные процессы гарантированно завершаются вместе с программой, память не утекает даже после сбоев, а окно обновлений теперь говорит на вашем языке — с переключателем Русский/English.
